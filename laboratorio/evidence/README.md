# Evidencias

Esta carpeta reunirá las evidencias finales de las pruebas.

## Evidencias requeridas

- Acceso HTTPS permitido.
- USERS → DB/3306 bloqueado.
- WEB → DB/3306 permitido.
- WEB → DB en otro puerto bloqueado.
- SQLi detectado por IPS.
- IP atacante en cuarentena.
- Descarga EXE bloqueada.
- Evento de protección DoS.
- DHCP y direccionamiento de VLANs.
- NAT y conectividad hacia Internet.
